# 古风水印（Android）

给照片添加古风水印的小应用，共 70 多款：

| 分类 | 内容 |
| --- | --- |
| 印章 | 白文方章、朱文方章、圆章（山河无恙、岁月静好、清风明月……） |
| 诗句 | 竖排古诗句（落霞与孤鹜齐飞、海上生明月……） |
| 节气 | 二十四节气圆章，按季节配色 |
| 装饰 | 梅花枝、祥云、新月、圆月、竹叶 |
| 落款 | 竖排日期（自动取当天），可带“清欢”小印 |

水印均由代码绘制，无需图片素材。

## 使用
1. 点「选择照片」。
2. 底部选分类，点一个水印加到照片上。
3. 单指拖动，双指缩放 + 旋转；点选水印后可换颜色（朱红/墨黑/月白/鎏金/黛青），拖动滑块调透明度。
4. 「删除」删掉选中水印，「清空」删掉全部，「保存」导出到 相册/古风水印（原图分辨率，最长边限 2560px）。

## 构建
- 用 Android Studio（Koala 或更新）打开本文件夹，等待 Gradle 同步后点 Run。
- minSdk 29（Android 10），compileSdk 34，Kotlin 1.9.24，AGP 8.5.2。

## 扩展
- 加印章/节气：在 `WatermarkFactory.all` 里加文字即可。
- 加诗句：在 `poems` 列表里加一句，用“，”分列。
- 想用自己的图片素材：把 PNG 放进 `res/drawable`，用 `BitmapFactory` 包成 `WatermarkSpec`。
